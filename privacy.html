개인정보처리방침

시행일: 2026년 10월 30일

여의도파민 업로더(이하 "이 프로그램")는 유튜브 채널 여의도파민 운영자가 본인 채널에 영상을 업로드하기 위해 사용하는 개인용 프로그램입니다.

1. 사용하는 권한과 정보

  • YouTube 동영상 업로드 (youtube.upload): 운영자가 만든 영상을 본인 채널에 업로드하고 공개 시각을 예약합니다.
  • YouTube 계정 보기 (youtube.readonly): 본인 채널 이름과 이미 예약된 영상 목록을 확인해, 같은 시각에 중복 업로드되지 않게 합니다.

2. 정보의 저장

로그인 정보(접근 토큰)는 운영자 본인 컴퓨터의 프로그램 폴더에만 저장되며, 외부 서버로 전송하거나 따로 수집하지 않습니다.

3. 제3자 제공

이 프로그램은 Google 사용자 데이터를 제3자에게 제공·판매·공유하지 않으며, 광고 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 프로그램이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요구사항 포함)을 따릅니다.

5. 권한 철회

언제든지 Google 계정 → 보안 → 타사 앱 액세스에서 이 프로그램의 권한을 해제할 수 있으며, 프로그램 폴더의 youtube_token.json 파일을 지우면 저장된 로그인 정보가 삭제됩니다.
